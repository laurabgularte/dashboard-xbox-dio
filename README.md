# 📊 Dashboard de Vendas - Xbox

Este repositório contém a solução desenvolvida para o desafio de criação de um dashboard analítico de vendas em Excel, com foco em transformação de dados brutos em insights visuais claros para a tomada de decisões.

---

## 🚀 Sobre o Projeto
O objetivo principal foi estruturar uma base de dados de vendas de produtos Xbox, aplicando técnicas de tratamento de dados, modelagem com tabelas dinâmicas e construção de um painel interativo (Dashboard).

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Microsoft Excel**: Tratamento de dados, Tabelas Dinâmicas, Funções Avançadas, Gráficos Dinâmicos e Segmentação de Dados (Slicers).
* **Git & GitHub**: Versionamento de código e documentação do projeto.

---

## 📈 Principais Indicadores (KPIs) e Visualizações
O dashboard final apresenta as seguintes informações estratégicas:
* **Faturamento Total e Volume de Vendas**
* **Ticket Médio**
* **Evolução temporal das vendas**
* **Desempenho por Categoria de Produto (Consoles, Jogos, Acessórios, etc.)**
* **Filtros interativos por período e região**
